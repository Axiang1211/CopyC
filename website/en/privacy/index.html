Privacy Policy

Your clipboard stays on your computer.

CopyC works entirely on your computer. It never uploads, sells or shares anything you copy, and it does not collect personal data.

Last updated: October 18, 2026 · Applies to CopyC 1.0 and later (Windows, macOS and Microsoft Store versions)

  • Processed locally What you copy is only used to draw the confirmation on your own computer. It never leaves it.
  • No uploads, no tracking No analytics, ads or trackers. The only network request is an update check, which you can turn off.
  • No account No sign-in, no account, and nothing is ever sold or shared.

What CopyC reads

  • Clipboard content: each time you copy, CopyC reads the clipboard to work out what kind of content it is (text, image, files, color, link) and show a confirmation. It listens to the system clipboard event and does not log keystrokes.
  • The foreground app's name: to show which app you copied from and to apply your app blocklist.
  • Whether an app is fullscreen: to switch to an unobtrusive indicator while you watch videos, play games or present.

What CopyC stores

  • Recent copies: up to 20 items, kept in memory only. They are gone when you quit the app and are never written to disk.
  • Your settings: such as position, language and app blocklist, saved in a settings file on your computer.

Content that password managers mark as confidential, and content that looks like a password or key, is masked automatically. With Privacy mode on, confirmations and recent copies show only the content type, never the content.

Update check

The version downloaded from the website asks GitHub for the latest version number when it starts (and once a day while it keeps running), and lets you know if a new version is available on the website. The request contains nothing you copied and no personal data; as with any web request, GitHub sees your IP address. You can turn it off in Preferences → General → Check for updates. The Microsoft Store version is updated by the Store, does not perform this check and makes no network connections.

What CopyC never does

  • It never sends what you copy or any personal data over the network, and contains no analytics, ads or trackers.
  • It has no accounts and needs no sign-in.
  • It never sells or shares data with third parties.

This website

This website (copyc.app.dreamsworld.top) is hosted on Cloudflare and uses cookie-free Cloudflare Web Analytics to count anonymous visits. The download section asks GitHub for the latest version number. None of this involves the app.

Children's privacy

CopyC does not collect personal data from anyone, including children under 13.

Changes

If this policy changes, we will update this page and the date above.
