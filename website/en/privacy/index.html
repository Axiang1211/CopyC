Privacy Policy

Your clipboard stays on your computer.

CopyC works entirely on your computer. It never uploads, sells or shares anything you copy, and it does not collect personal data.

Policy version 1.1 · Last updated: October 26, 2026 · Applies to all versions of CopyC (Windows, macOS and Microsoft Store versions)

  • Processed locally What you copy is only used for the confirmation and your history on your own computer. It never leaves it.
  • No uploads, no tracking No analytics, ads or trackers. The only network request is an update check, which you can turn off.
  • No account No sign-in, no account, and nothing is ever sold or shared.

What CopyC reads

  • Clipboard content: each time you copy, CopyC reads the clipboard to work out what kind of content it is (text, image, files, color, link) and show a confirmation. It listens to the system clipboard event and does not log keystrokes.
  • The foreground app's name: to show which app you copied from and to apply your app blocklist.
  • Whether an app is fullscreen: to switch to an unobtrusive indicator while you watch videos, play games or present.

What CopyC stores

  • History (from 1.0.8): the text, links and color codes you copy, plus image thumbnails and file locations (paths), are saved in a local database on your computer so you can search and copy them again later. By default up to 1,000 entries are kept and the oldest are removed automatically. You can change the limit (100–5,000), delete single entries, clear everything, or turn history off in Preferences → History. Files themselves are never copied or stored.
  • Passwords are not saved: content that password managers mark as confidential, and content that looks like a password or key, is not written to history by default. It is only saved if you turn on “Save passwords and sensitive content” (stored in plain text on your computer and still masked in the list). Turning that option off deletes the saved passwords.
  • App blocklist: nothing copied from an app on your blocklist is written to history.
  • “Recent copies” on the Overview: up to 20 items, kept in memory only and gone when you quit the app.
  • Your settings: such as position, language and app blocklist, saved in a settings file on your computer.

All of this stays on your computer and is never uploaded to any server. To remove everything, click Clear in Preferences → History and then uninstall. The Microsoft Store version deletes all of its data when uninstalled; for the other versions the data lives in “%APPDATA%\top.dreamsworld.copyc” on Windows and “~/Library/Application Support/top.dreamsworld.copyc” on macOS, and you can delete it by hand.

Masking and Privacy mode

Content that password managers mark as confidential, and content that looks like a password or key, is masked in confirmations automatically. With Privacy mode on, confirmations, recent copies and the History list show only the content type, never the content, which is handy when sharing your screen.

Update check

The version downloaded from the website asks GitHub for the latest version number when it starts (and once a day while it keeps running), and lets you know if a new version is available on the website. The request contains nothing you copied and no personal data; as with any web request, GitHub sees your IP address. You can turn it off in Preferences → General → Check for updates. The Microsoft Store version is updated by the Store, does not perform this check and makes no network connections.

What CopyC never does

  • It never sends what you copy or any personal data over the network, and contains no analytics, ads or trackers.
  • It has no accounts and needs no sign-in.
  • It never sells or shares data with third parties.

This website

This website (copyc.app.dreamsworld.top) is hosted on Cloudflare and uses cookie-free Cloudflare Web Analytics to count anonymous visits. The download section asks GitHub for the latest version number. None of this involves the app.

Children's privacy

CopyC does not collect personal data from anyone, including children under 13.

Future features

CopyC keeps growing. If a future version adds anything that lets data leave this computer (for example sending or syncing between your own devices), we will update this policy before it ships, explaining what is sent, where it goes, how long it is kept and how to turn it off. You will decide whether to turn such features on.

Changes to this policy

Every time this policy changes we update this page, raise the policy version above and describe the change in the version history below. If you don't agree with a revised policy, you can stop using and uninstall CopyC.
