隱私權政策

最後更新：2026 年 10 月 18 日・適用 CopyC 1.0 以上版本（Windows、macOS、Microsoft Store 版）

一句話版本：CopyC 完全在你的電腦上運作。它不會上傳、販售或分享你複製的任何內容，也不會收集你的個人資料。App 唯一的網路連線是檢查新版本。

CopyC 會讀取什麼

  • 剪貼簿內容：你每次複製時，CopyC 會讀取剪貼簿，用來判斷內容類型（文字、圖片、檔案、顏色、網址）並顯示提示。它使用系統的剪貼簿事件，不會記錄鍵盤輸入。
  • 前景 App 名稱：用來在提示中顯示「從哪個 App 複製」，以及套用你設定的 App 黑名單。
  • 是否處於全螢幕：用來在你看影片、玩遊戲或簡報時改為不打擾的顯示方式。

CopyC 會儲存什麼

  • 最近複製紀錄：最多 20 筆，只存在記憶體中，關閉 App 後就會消失，不會寫入硬碟。
  • 你的設定：例如提示位置、語言、App 黑名單，存在你電腦上的設定檔裡。

密碼管理器標記為機密的內容、疑似密碼或金鑰的內容，CopyC 會自動遮蔽；開啟「隱私模式」後，所有提示與最近紀錄都只顯示類型、不顯示內容。

檢查更新

從官網下載的版本，會在開啟時（以及常駐期間每天一次）向 GitHub 查詢最新的版本號，有新版就提醒你前往官網下載。這個請求不包含你複製的內容或任何個人資料；跟一般瀏覽網頁一樣，GitHub 會看到你的 IP 位址。你可以在「偏好設定 → 一般 → 自動檢查更新」關閉。Microsoft Store 版由商店負責更新，不會進行這項檢查，也不會連網。

CopyC 不會做的事

  • 不會把你複製的內容或任何個人資料傳送到網路上，也不包含分析、廣告或追蹤程式。
  • 不會建立帳號，不需要登入。
  • 不會把資料販售或分享給任何第三方。

官方網站

本網站（copyc.app.dreamsworld.top）由 Cloudflare 託管，並使用不設置 Cookie 的 Cloudflare Web Analytics 統計匿名的瀏覽次數。下載區會向 GitHub 查詢最新版本號。這些都與 App 本身無關。

兒童隱私

CopyC 不會收集任何人的個人資料，包括 13 歲以下的兒童。
