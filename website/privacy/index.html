隱私權政策

你的剪貼簿，由你決定去哪裡。

CopyC 預設完全在本機運作。只有你自己登入 Google 開啟同步時，文字類內容才會先在你的電腦上加密，再傳到你的其他電腦與你自己的 Google Drive。我們不販售、不分享，也看不到你複製的內容。

政策版本 1.3・最後更新：2026 年 10 月 28 日・適用 CopyC 所有版本（Windows、macOS、Microsoft Store 版）

  • 預設只在本機 不登入同步時，複製的內容只用來在你的電腦上產生提示與歷史紀錄，不會離開你的電腦。
  • 同步是選用的，而且加密 同步預設關閉。開啟後內容在你的電腦上就先加密，中繼伺服器看不到內容。圖片、檔案與密碼永遠不會同步。
  • 不追蹤、不販售 沒有分析、廣告或追蹤程式；不會把資料販售或分享給任何人。

CopyC 會讀取什麼

  • 剪貼簿內容：你每次複製時，CopyC 會讀取剪貼簿，用來判斷內容類型（文字、圖片、檔案、顏色、網址）並顯示提示。它使用系統的剪貼簿事件，不會記錄鍵盤輸入。
  • 前景 App 名稱：用來在提示中顯示「從哪個 App 複製」，以及套用你設定的 App 黑名單。
  • 是否處於全螢幕：用來在你看影片、玩遊戲或簡報時改為不打擾的顯示方式。

CopyC 在你電腦上儲存什麼

  • 歷史紀錄：你複製過的文字、連結、色碼，以及圖片的縮圖、檔案的位置（路徑），存在你電腦上的本機資料庫，讓你之後搜尋、重新複製。預設最多 1,000 筆，超過時自動刪除最舊的；你可以改成 100～5,000 筆、逐筆刪除、一鍵全部清除，或在「偏好設定 → 歷史紀錄」整個關閉。檔案本身不會被複製或保存。
  • 密碼預設不保存：密碼管理器標記為機密的內容、疑似密碼或金鑰的內容，預設不會寫入歷史紀錄。只有你自己開啟「保存密碼與敏感內容」時才會保存（以明文存在本機，列表中仍會遮蔽）；關閉這個選項時，已保存的密碼會一併刪除。
  • App 黑名單：設為黑名單的 App 複製的內容，不會寫入歷史紀錄，也不會同步。
  • 總覽裡的「最近複製」：最多 20 筆，只存在記憶體中，關閉 App 後就會消失。
  • 你的設定：例如提示位置、語言、App 黑名單，存在你電腦上的設定檔裡。
  • 登入同步時：你的 Google 帳號 Email、Google 帳號 ID、一個隨機產生的裝置 ID，以及 Google 發給 CopyC 的授權憑證（refresh token）。Windows 版的授權憑證存在系統的「認證管理員」，macOS 版存在只有你本人可讀的設定檔。

想完全移除時，先在「偏好設定 → 歷史紀錄」按「清除」（有登入同步的話也先在「同步」按「刪除雲端資料」），再解除安裝即可。Microsoft Store 版解除安裝時會自動刪除所有本機資料；其他版本的資料位置：Windows 在「%APPDATA%\top.dreamsworld.copyc」，macOS 在「~/Library/Application Support/top.dreamsworld.copyc」，也可以手動刪除。

跨裝置同步（選用，1.1.0 起）

同步預設關閉，只有你在「偏好設定 → 同步」或新手引導中按「使用 Google 登入」才會啟用。啟用後：

  • 會同步的內容：只有文字類的複製內容，也就是文字、連結、Email、電話與色碼，以及複製的時間與這台電腦的名稱。
  • 永遠不會同步：圖片、檔案與檔案路徑、密碼與敏感內容（不論你是否開啟「保存密碼」），以及黑名單 App 複製的內容。單筆超過 256 KB 的文字也不會同步。
  • 端對端加密：內容在你的電腦上就以 XChaCha20-Poly1305 加密。加密金鑰在你第一台登入的裝置上產生，存放在你 Google Drive 的 CopyC 專用資料夾，讓你同一個 Google 帳號的其他電腦可以解密。Cloudflare 與我們的伺服器都拿不到金鑰，也解不開內容。
  • 歷史備份（Google Drive）：加密後的紀錄存在你自己 Google Drive 的「應用程式專用資料夾」（appDataFolder）。這個資料夾在雲端硬碟裡看不到，CopyC 也只能存取這個資料夾，看不到你的其他檔案。備份保留 90 天，之後由 CopyC 自動刪除。你在一台電腦刪除的紀錄，其他電腦也會跟著刪除。
  • 即時同步（Cloudflare）：你複製文字時，加密後的內容會經由我們在 Cloudflare 上的中繼伺服器（copyc.app.dreamsworld.top）轉給你登入同一個 Google 帳號、正在連線的其他電腦，對方會直接放進剪貼簿（可以關閉）。中繼伺服器只用你的 Google 登入憑證確認你是哪個帳號，並收到每台電腦隨機產生的裝置編號（用來避免重複轉送），不保存任何內容，也不保存你的 Email；和一般網路連線一樣，Cloudflare 會處理你的 IP 位址等連線資訊。
  • 同一個網路直接互傳（CopyC 1.1.1 起）：開啟即時同步時，CopyC 會在你目前連的網路（例如家裡或公司的 Wi-Fi）裡定期廣播一個加密的訊號，找出同一個網路裡、登入同一個 Google 帳號的其他電腦，再把加密後的內容直接傳給它們，不經過網際網路；沒有直接收到的電腦才改由上面的 Cloudflare 中繼轉送。訊號裡的裝置編號、名稱與連線埠同樣用你的金鑰加密，同一個網路裡的其他人看不到內容，也認不出是哪個帳號，只看得到這台電腦的 IP 位址正在發送訊號。這項功能可以在「偏好設定 → 同步 → 同一個網路直接互傳」關閉。
  • Google 授權範圍：CopyC 只要求 openid、email（顯示你登入的帳號）與 drive.appdata（只能讀寫 CopyC 自己的隱藏資料夾）。

你可以隨時關閉「即時同步」或「備份歷史紀錄」；按「登出」會撤銷授權、刪除這台電腦上的授權憑證，並刪除其他電腦同步來的紀錄；按「刪除雲端資料」會刪除 Google Drive 裡 CopyC 的所有備份與金鑰。你也可以在 Google 帳戶的第三方存取權移除 CopyC。

CopyC 使用及傳輸從 Google API 取得的資訊時，會遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定：這些資料只用來提供你看得到的同步功能，不會用於廣告、不會販售，也不會交給任何第三方，我們也不會由人工讀取。

遮蔽與隱私模式

密碼管理器標記為機密的內容、疑似密碼或金鑰的內容，CopyC 會在提示中自動遮蔽。開啟「隱私模式」後，所有提示、最近紀錄與歷史紀錄列表都只顯示類型、不顯示內容，適合開會分享螢幕時使用。

檢查更新

從官網下載的版本，會在開啟時（以及常駐期間每天一次）向 GitHub 查詢最新的版本號，有新版就提醒你前往官網下載。這個請求不包含你複製的內容或任何個人資料；跟一般瀏覽網頁一樣，GitHub 會看到你的 IP 位址。你可以在「偏好設定 → 一般 → 自動檢查更新」關閉。Microsoft Store 版由商店負責更新，不會進行這項檢查。

CopyC 不會做的事

  • 沒有登入同步時，不會把你複製的內容傳送到網路上；登入同步時，也只傳送加密後的文字類內容。
  • 不包含分析、廣告或追蹤程式。
  • 不需要建立 CopyC 帳號；同步使用你自己的 Google 帳號，而且是選用的。
  • 不會把資料販售或分享給任何第三方。

官方網站

本網站（copyc.app.dreamsworld.top）由 Cloudflare 託管，並使用不設置 Cookie 的 Cloudflare Web Analytics 統計匿名的瀏覽次數。下載區會向 GitHub 查詢最新版本號。即時同步的中繼伺服器也在這個網域，說明見上方「跨裝置同步」。

兒童隱私

CopyC 不會把任何人的個人資料收集到我們這邊，包括 13 歲以下的兒童。同步功能需要 Google 帳號，並適用 Google 對帳號年齡的規定。

之後的新功能

CopyC 會持續加入新功能。如果之後的版本加入任何會讓資料離開你這台電腦的新功能（例如在同一個網路內直接傳送檔案），我們會在推出前先更新這份政策，清楚說明傳送什麼、傳到哪裡、保存多久，以及如何關閉。這類功能都會由你自己決定是否開啟。
