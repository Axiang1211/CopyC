常見問題

點餐前，先問老闆。

CopyC 會把我複製的內容傳到網路上嗎？

不會。複製內容只用來在本機產生提示；最近的紀錄只存在記憶體中，關閉程式就清除。CopyC 唯一的連網動作是向 GitHub 查詢最新版本號，不包含任何內容，也可以在設定裡關閉。

它是靠監聽鍵盤來偵測的嗎？

不是。CopyC 監聽的是系統剪貼簿的變更事件，不記錄任何按鍵。所以不論用快捷鍵、右鍵選單還是網頁上的「一鍵複製」按鈕都會觸發；沒有選取內容時按 Ctrl+C 也不會誤報。

為什麼安裝時會看到安全性警告？

目前的安裝包尚未取得付費程式碼簽章憑證，所以 Windows SmartScreen 與 macOS Gatekeeper 會提醒你。依照下載卡片裡的「安裝小提醒」操作即可。Windows 使用者也可以改從 Microsoft Store 安裝，就不會出現這個警告，之後也會自動更新。

為什麼叫 CopyC？

Copy 跟馬來語的 Kopi（咖啡）唸起來幾乎一樣，而 Kopi C 是南洋咖啡店裡加淡奶的招牌咖啡。複製一下，就像點了一杯熟悉的 Kopi。
